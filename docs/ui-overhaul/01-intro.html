2. Concept — "Ink greeting"

Greeting is written by a pen — real stroke order, pressure-varied width, tapered ends — then the ink flies into the header logo slot (shared-element handoff) as the hero blurs in. One continuous motion, not two scenes.

Per-theme ink

light
Sumi ink, near-black, no glow. Slight variationPlugin "Subtle" → human wobble. Over clouds.
dark
Luminous ink — glowPlugin tinted --primary; nib leaves bright head that cools. Matches LightRays.
terminal
Phosphor green, boilPlugin low (CRT jitter), monospace-ish hand font, blinking cursor as nib.

Ink colours → new CSS tokens in app/globals.css (--intro-ink, --intro-glow) per theme. No inline hex (CLAUDE.md UI rule).

Key decisions

  1. Overlay, not branch. Today About renders either intro or content. New: content always rendered underneath (SEO/static HTML has real content, no layout jump), overlay on top, inert during play.
  2. Once ever → localStorage + versioned key. Bump v1→v2 when intro redesigned → everyone sees new one once.
  3. Skip = jump Tegaki to controlled end time (time = engine.duration) then run handoff at 2× speed — skip still feels designed, not a cut. Ignore modifier keys + : so palette shortcut never eaten.
  4. No-flash first paint: tiny inline script in <head> sets data-intro="pending" on <html> if flag unset → CSS hides hero before hydration. Same pattern next-themes uses for theme.
  5. Reduced motion (OS or app animationPref, existing isReducedMotion) → never play, mark seen.
  6. All text via i18n: intro.greeting, intro.welcome, intro.skip, command.intro in en + ja.
